Stitch Reserve support

Plan a project

Add a fabric cut with its width and remaining length. Create a project and enter requirements from your pattern. Reserve a suitable cut for each fabric requirement and record the notions you have. The readiness view shows what is still missing.

A requirement needs one continuous suitable cut. Reservations hold stock without consuming it. Archiving a project releases its reservations. Complete a project only after checking the consumption confirmation; that step subtracts the reserved stock.

Protect your records

Export a JSON backup in Settings and confirm the file reached the location you chose. Keep a copy before clearing app storage or uninstalling. Import validates a backup before replacing the current notebook. Purchase access is never imported from a backup.

Permanent Pro

The free app supports one active project and unlimited archived projects. Pro adds multiple active projects and reusable requirement templates. Restore a purchase using the Google Play account that bought it. If payment is uncertain, check your Play order history and restore before attempting another purchase.

Get help

Email pierdo.dev@gmail.com with the app version, Android version, what happened and steps to reproduce it. Only send sewing records if you choose to share them to explain the problem. Never send passwords or payment-card details.
